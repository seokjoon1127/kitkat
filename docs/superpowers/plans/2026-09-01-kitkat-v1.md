# kitkat v1 구현 계획 (2026-09-01, rev2 — 적대적 검토 21건 반영)

> **For agentic workers:** 이 계획은 Workflow 서브에이전트들이 웨이브(WF-1~WF-4) 단위로 실행한다.
> 각 에이전트는 [Global Constraints + Contracts C1~C7 + 자기 태스크 섹션]을 프롬프트로 받는다.
> 태스크끼리는 **서로 다른 디렉터리만** 건드린다. 빌드 의존이 있는 태스크는 같은 웨이브 안에서 **체인(순차)** 으로 실행된다.

**Goal:** 쇼츠/광고 제작 에이전트가 API로 부리고, 사람은 브라우저 URL에서 풀 타임라인 편집을 하는 로컬 영상 편집 서버.
**v1 범위(정확히):** PRD §5 ①군 — 단 MOV/알파 내보내기·커버 지정·정지화면·손떨림 보정은 W5 이관. ②군 — 단 LUT·커브 속도·스티커/GIF 클립·비트 마커·더킹·피치 보정·텍스트 템플릿·색조정 커브·파티클류 화면 효과는 W5 이관. ③군 — 자동자막(Whisper)만, 나머지는 W5.
**W4 검증·리뷰 에이전트는 "W5 이관분 미구현"을 버그로 취급하지 않는다.**

**Architecture:** 하나의 JSON 프로젝트 문서(P2)를 진실의 원천으로, 공유 engine 패키지가 모든 편집 명령을 적용한다(서버·UI 동일 코드 = D5). 렌더는 Remotion 컴포지션 + FFmpeg. 미리보기는 같은 컴포지션을 @remotion/player로 재생(WYSIWYG). 편집 중엔 540p 프록시(P3).

**Tech Stack:** Node 22 · TS 5(strict, ESM) · npm workspaces · Zod 3 · Fastify 5 · Remotion 4.0.519(renderer/player/bundler) · React 18 · Vite 6 · Zustand · vitest · execa · @modelcontextprotocol/sdk · Python 3.11(faster-whisper CPU int8)

**Spec:** `PRD.md`

## Global Constraints

- **전부 로컬.** 외부 유료 API 금지. fal.ai 금지. Anthropic API(`anthropic` SDK/`api.anthropic.com`) 금지. 예외 없음.
- **시간은 정수 ms.** 프레임 변환은 렌더러에서만 (`Math.round(ms * fps / 1000)`).
- **좌표 정규화:** transform.x/y는 캔버스 중심 원점·캔버스 크기 대비 비율. scale 1 = contain-fit. rotation은 deg. fontSize는 높이 1080 기준 px(비례 스케일).
- **ESM 전용.** TS 해석: **ui 패키지만 `moduleResolution: "Bundler"`**, 그 외 전 패키지는 `NodeNext`이며 **상대 import에 반드시 `.js` 확장자**를 쓴다 (`import { x } from './apply.js'`) — 안 쓰면 다른 패키지에서 런타임 ERR_MODULE_NOT_FOUND.
- **문서(ProjectDoc)에 저장되는 모든 경로는 forward slash(`/`) 전용.** Windows에서도 `\` 금지 — 경로 생성 후 `replaceAll('\\','/')`. Zod 스키마의 src류 필드에 백슬래시 거부 regex를 넣는다.
- **인코더:** `detectEncoder()`는 **ffmpeg 직접 인코딩 경로(프록시·역재생·GIF)에만** 적용 — qsv 선택 시 `-global_quality 26`(qsv는 `-crf` 미지원), 아니면 libx264+crf. **최종 렌더(renderMedia)는 항상 Remotion 내장 x264** — detectEncoder와 무관 (이 머신엔 NVENC 없음).
- 서버 포트 **5757**. 미디어 `media/`(assets/, proxies/, waveforms/, thumbs/, renders/, derived/, samples/), 문서 `data/projects/<id>.json`.
- 검증 명령: 자기 패키지 `npm run build -w @kitkat/<name>` 와 `npm run test -w @kitkat/<name>` 의 실제 통과 출력.
- **파일 소유권:** 자기 태스크 Files 목록의 경로 + 자기 패키지 안의 `test/` 파일만 생성/수정. **저장소 루트의 설정 파일(루트 package.json·tsconfig.base.json·.gitignore)은 수정 금지.** 자기 패키지의 package.json은 필요 시 수정 가능. 다른 패키지의 **소스 수정은 금지**지만 빌드 실행(`npm run build -w @kitkat/xxx`)으로 dist를 만드는 것은 허용. **npm install 금지** (의존성은 이미 설치됨).
- UI에 보이는 문자열은 한국어.

## 실행 그래프 (오케스트레이터용)

- **WF-1 (코어):** 체인① schema → engine · 체인② media · 체인③ 샘플/데모 스크립트 — 동시 3체인, 총 4에이전트
- **WF-2 (렌더·서버):** 체인① renderer → server · 체인② mcp · 체인③ ai 구현 — 동시 3체인, 총 4에이전트
- **WF-3 (UI):** ui-shell ∥ timeline ∥ inspector (파일 분리 병렬) → ui-verify(전체 vite build + 오류 수정) — 4에이전트
- **WF-4 (통합):** E2E 통합(샘플 렌더·자막·MCP·브라우저 스모크) → 발견 버그 픽스 → 적대적 리뷰 3렌즈 → CONFIRMED 픽스
- 개별 UI 태스크(W3-A/B/C)는 전체 vite build를 완료 기준으로 삼지 않는다(형제 파일 미완성 경합) — 자기 파일의 정합성과 자기 단위 테스트만. 전체 빌드는 ui-verify 담당.
- ai 패키지는 W0.5에서 오케스트레이터가 **타입 스텁**(C6 시그니처 그대로, 호출 시 AiUnavailableError throw)을 만들어 빌드해 둔다 → server는 WF-2에서 정적 import 가능. W3-E(→WF-2 체인③)는 스텁의 내부 구현만 교체한다(공개 시그니처 변경 금지).

## 공유 계약 (Contracts) — 모든 태스크가 이 이름·타입을 그대로 쓴다

### C1. 프로젝트 문서 스키마 (`@kitkat/schema`가 구현·export)

```ts
export const SCHEMA_VERSION = 1;

export type Background =
  | { kind: 'color'; color: string /* #rrggbb */ }
  | { kind: 'blur'; amount: number /* px 4..80 */ }     // 맨 아래 비디오/이미지 클립을 확대·블러해 여백 채움
  | { kind: 'image'; assetId: string };

export type ProjectDoc = {
  schemaVersion: 1;
  id: string;                    // nanoid
  name: string;
  revision: number;              // 명령 배치 적용마다 +1
  settings: { width: number; height: number; fps: number; background: Background };
  assets: Record<string, Asset>;
  tracks: Track[];               // 배열 순서 = 아래(0) → 위 렌더 순서
};

export type Asset = {
  id: string;
  kind: 'video' | 'audio' | 'image';
  src: string;                   // media/ 기준 상대경로, forward slash 전용
  name: string;
  duration?: number;             // ms
  width?: number; height?: number;
  proxySrc?: string;             // "proxies/<id>.mp4" (540p)
  waveformSrc?: string;          // "waveforms/<id>.json"
  thumbSrc?: string;             // "thumbs/<id>.jpg" (video/image 대표 썸네일 1장)
  reversedSrc?: string;          // "derived/<id>.rev.mp4"
};

export type Track = {
  id: string;
  kind: 'video' | 'audio' | 'text' | 'overlay';
  name: string;
  volume?: number;               // 0..2 기본 1 — 트랙 전체 배율(audio/video 트랙용)
  muted?: boolean; locked?: boolean; hidden?: boolean;
  clips: Clip[];                 // start 오름차순, 같은 트랙 내 겹침 금지
};

export type Transform = { x: number; y: number; scale: number; rotation: number;
                          flipH?: boolean; flipV?: boolean };
export type Crop = { x: number; y: number; w: number; h: number };  // 소스 대비 정규화 0..1, 기본 전체
export type Keyframe = { time: number /* 클립 시작 기준 ms */;
  prop: 'x' | 'y' | 'scale' | 'rotation' | 'opacity' | 'volume';
  value: number; easing: 'linear' | 'easeIn' | 'easeOut' | 'easeInOut' };
export type Effect = { id: string; type: EffectType; params: Record<string, number | string | boolean> };
export type Transition = { type: TransitionType; duration: number /* ms */ };
export type Mask = { shape: 'rect' | 'circle' | 'linear'; feather: number /* 0..1 */; invert?: boolean;
                     x: number; y: number; w: number; h: number };
export type ChromaKey = { color: string; similarity: number; smoothness: number };

export type ClipBase = {
  id: string;
  start: number; duration: number;   // 타임라인 ms
  transform?: Transform;             // 기본 {x:0,y:0,scale:1,rotation:0}
  crop?: Crop;
  opacity?: number;                  // 0..1 기본 1
  keyframes?: Keyframe[];
  effects?: Effect[];
  transitionIn?: Transition; transitionOut?: Transition;
};

export type VideoClip = ClipBase & {
  kind: 'video'; assetId: string;
  in: number; out: number;           // 소스 구간 ms (out > in)
  speed: number;                     // 0.1..100, duration === (out-in)/speed (±1ms)
  reversed?: boolean;
  volume: number;                    // 0..2 기본 1
  fadeIn?: number; fadeOut?: number; // ms (오디오 페이드)
  blendMode?: 'normal'|'multiply'|'screen'|'overlay'|'darken'|'lighten'|'color-dodge'|'color-burn'|'hard-light'|'soft-light'|'difference';
  mask?: Mask; chromaKey?: ChromaKey;
};
export type ImageClip = ClipBase & { kind: 'image'; assetId: string;
  blendMode?: VideoClip['blendMode']; mask?: Mask };
export type AudioClip = {
  id: string; start: number; duration: number;
  kind: 'audio'; assetId: string;
  in: number; out: number; speed: number;
  volume: number; fadeIn?: number; fadeOut?: number;
  keyframes?: Keyframe[];            // prop 'volume'만 유효
};
export type WordTiming = { text: string; start: number; duration: number };  // start = 클립 시작 기준 ms
export type TextClip = ClipBase & {
  kind: 'text'; text: string; style: TextStyle;
  animationIn?: { type: TextAnimType; duration: number };
  animationOut?: { type: TextAnimType; duration: number };
  words?: WordTiming[]; highlightColor?: string;
};
export type TextStyle = {
  fontFamily: string;                // 기본 "Pretendard, 'Malgun Gothic', sans-serif"
  fontSize: number; color: string; bold?: boolean; italic?: boolean;
  strokeColor?: string; strokeWidth?: number;
  backgroundColor?: string; shadow?: boolean;
  align: 'left' | 'center' | 'right';
  letterSpacing?: number; lineHeight?: number;
};
export type Clip = VideoClip | ImageClip | AudioClip | TextClip;

export const TRANSITION_TYPES = ['fade','slideLeft','slideRight','slideUp','slideDown','wipeLeft','zoomIn','zoomOut'] as const;
export type TransitionType = typeof TRANSITION_TYPES[number];
export const EFFECT_TYPES = ['brightness','contrast','saturation','hue','blur','vignette','grayscale','sepia','invert'] as const;
export type EffectType = typeof EFFECT_TYPES[number];
// params: brightness/contrast/saturation {amount 0..2 기본1}, hue {deg -180..180}, blur {px 0..50},
//         vignette/grayscale/sepia/invert {amount 0..1}
export const TEXT_ANIM_TYPES = ['fade','slideUp','popIn','typewriter','wordHighlight'] as const;
export type TextAnimType = typeof TEXT_ANIM_TYPES[number];
```

추가 export: `ProjectDocSchema`(Zod, src류 필드에 `/^[^\\]+$/`), `validateDoc(x: unknown): ProjectDoc`,
`createEmptyProject(opts: {name: string; width?: number; height?: number; fps?: number}): ProjectDoc`
(기본 1080×1920 30fps, background {kind:'color', color:'#000000'}, 트랙 3개: video/text/audio), `newId(): string`.

### C2. 편집 명령 (`@kitkat/engine`이 구현·export) — 총 19종

```ts
export type Command =
  | { type: 'renameProject'; name: string }
  | { type: 'setSettings'; settings: Partial<ProjectDoc['settings']> }
  | { type: 'addAsset'; asset: Asset }
  | { type: 'removeAsset'; assetId: string }              // 참조 클립 있으면 EngineError
  | { type: 'updateAsset'; assetId: string; patch: Partial<Asset> }
  | { type: 'addTrack'; track: { id: string; kind: Track['kind']; name: string }; index?: number }
  | { type: 'removeTrack'; trackId: string }
  | { type: 'reorderTrack'; trackId: string; index: number }
  | { type: 'setTrackProps'; trackId: string; patch: { name?: string; volume?: number; muted?: boolean; locked?: boolean; hidden?: boolean } }
  | { type: 'addClip'; trackId: string; clip: Clip }      // 겹침·트랙 kind 불일치 시 EngineError
  | { type: 'removeClip'; clipId: string }
  | { type: 'moveClip'; clipId: string; start: number; trackId?: string }
  | { type: 'splitClip'; clipId: string; at: number }     // at = 타임라인 절대 ms. text/image는 duration만 분할, words는 시간 기준 분배
  | { type: 'trimClip'; clipId: string; edge: 'start' | 'end'; to: number }
  //  ^ video/audio: in/out 재계산(소스 범위 초과 시 EngineError). text/image: start/duration만 조정
  | { type: 'setClipSpeed'; clipId: string; speed: number }   // video/audio 전용, duration 재계산
  | { type: 'setReversed'; clipId: string; reversed: boolean }
  | { type: 'updateClip'; clipId: string; patch: Record<string, unknown> }
  //  ^ transform/crop/opacity/volume/fades/blendMode/mask/chromaKey/text/style/animationIn·Out/words/
  //    highlightColor/transitionIn·Out/effects(배열 통째 교체) 등. kind/id/start/duration/in/out/speed는 patch 금지(EngineError)
  | { type: 'setKeyframes'; clipId: string; keyframes: Keyframe[] }
  | { type: 'restoreDoc'; doc: ProjectDoc };              // 문서 전체 교체(undo용). id는 기존 유지, revision은 applyCommands가 관리

export class EngineError extends Error { code: string }   // 'CLIP_NOT_FOUND'|'OVERLAP'|'BAD_PATCH'|'TRACK_KIND_MISMATCH'|...
export function applyCommand(doc: ProjectDoc, cmd: Command): ProjectDoc;    // 불변, revision 그대로
export function applyCommands(doc: ProjectDoc, cmds: Command[]): ProjectDoc; // 원자적 전체 적용 + revision+1
export function checkInvariants(doc: ProjectDoc): string[];
export function findClip(doc: ProjectDoc, clipId: string): { track: Track; clip: Clip; index: number } | null;
```

### C3. HTTP API (`@kitkat/server`) — 베이스 `http://127.0.0.1:5757`

| 메서드·경로 | 요청 | 응답 |
|---|---|---|
| `POST /api/projects` | `{name, width?, height?, fps?}` | `{doc}` |
| `GET /api/projects` | – | `{projects: {id,name,revision}[]}` |
| `GET /api/projects/:id` | – | `{doc}` |
| `DELETE /api/projects/:id` | – | `{ok: true}` |
| `POST /api/projects/:id/commands` | `{commands: Command[], baseRevision?: number, clientId?: string}` | `{revision}` / baseRevision 불일치 409 `{error, doc}` / EngineError 400 `{error}` |
| `POST /api/projects/:id/assets` | `{path}`(로컬 절대경로) 또는 multipart `file` | `{asset, jobId}` — 즉시 probe+addAsset, 프록시·파형·썸네일은 job 후처리 → `updateAsset` 브로드캐스트 |
| `POST /api/projects/:id/assets/:assetId/extract-audio` | – | `{asset}` — 해당 비디오의 오디오를 wav로 추출해 새 audio Asset 추가(addAsset 브로드캐스트) |
| `POST /api/projects/:id/render` | `{range?: {start,end}, proxy?, format?: 'mp4'|'gif', width?, height?, fps?, outName?}` | `{jobId}` — gif는 mp4 렌더 후 서버가 media.toGif 변환 |
| `GET /api/jobs/:jobId` | – | `{id, type, status:'queued'|'running'|'done'|'error', progress, result?: {url, path}, error?}` |
| `POST /api/projects/:id/captions` | `{assetId, trackId?, style?: Partial<TextStyle>, language?}` | `{jobId}` — 완료 시 text 트랙에 TextClip들 추가(words 포함) 브로드캐스트 |
| `GET /media/*` | – | media/ 정적 서빙 |
| `GET /p/:id` | – | 편집기 index.html |
| `GET /assets/*` | – | **packages/ui/dist/assets 정적 서빙** (vite 산출물 JS/CSS — 없으면 /p/:id 가 "UI 미빌드" 안내 HTML) |
| `GET /healthz` | – | `{ok: true, version}` |

**WS `GET /ws/projects/:id`** — @fastify/websocket **v11: 핸들러 시그니처는 `(socket, req)` 이고 socket이 ws WebSocket 그 자체**(`socket.send/on`; `connection.socket` 패턴은 폐지됨):
- 접속 직후 서버→ `{type:'doc', doc}`
- 명령 적용 시 서버→전 구독자 `{type:'commands', revision, commands, clientId?}` (POST에 실려온 clientId를 그대로 에코)
- **클라이언트는 자기 clientId의 브로드캐스트는 적용을 스킵**(이미 낙관 적용됨, revision만 채택). 남의 것은 revision 연속이면 `applyCommands` 로컬 적용, 불연속이면 클라→ `{type:'resync'}` → 서버→ `{type:'doc', doc}`
- job 진행: 서버→ `{type:'job', job}`
